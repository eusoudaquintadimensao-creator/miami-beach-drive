# Miami Beach Drive

Jogo 3D de dirigir e andar em Miami Beach: avenida estilo Ocean Drive, praia, palmeiras e prédios Art Déco.

## Como jogar

Abra o link do GitHub Pages no navegador (celular ou computador).

- **Computador:** WASD ou setas para andar/dirigir; E para entrar/sair do carro
- **Celular:** joystick na tela; botões para entrar no carro e mudar o horário

Dá para escolher dia, pôr do sol ou noite com neon, e ajustar a qualidade gráfica. O jogo guarda onde você parou.

## Tecnologias

HTML + JavaScript + [Three.js](https://threejs.org/) (CDN).
